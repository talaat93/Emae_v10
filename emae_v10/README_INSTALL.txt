EMAE V10 - INSTALLATION RAPIDE

1. Dézippez le dossier dans C:\xampp\htdocs\emae_v10
2. Ouvrez http://localhost/emae_v10/install.php
3. Remplissez :
   - Host : localhost
   - Port : 3306
   - Base : emae_v10
   - User : root
   - Password : vide sur XAMPP par défaut
4. Laissez Base URL vide sur XAMPP
5. Cliquez sur Installer

IMPORTANT
- Cette version réinitialise automatiquement les tables si vous relancez install.php sur la même base.
- Le fichier config/config.php est fourni en mode non installé pour éviter les redirections en boucle.
- L'admin est accessible après installation via /admin/login.php
